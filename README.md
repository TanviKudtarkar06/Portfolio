## Run locally

No build tools or dependencies required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

For the smoothest local development experience, use VS Code with the Live Server extension.


## Features

- Animated particle/circuit canvas background
- Neon cyberpunk / synthwave styling
- Responsive layout for mobile and desktop
- Scroll reveal animations and floating holographic illustration
- Interactive terminal commands: `help`, `about`, `skills`, `projects`, `coffee`, `clear`
- Neon palette switcher, glitch effect, sparkle confetti, tiny-win counter
- Light/dark visual toggle
- Reduced-motion preference support

## Important notes

The music player is a **silent visual demo**. The contribution grid and count are decorative mock data, and the project cards are example content. Replace these with accurate information before sharing the portfolio publicly.

Built with HTML, CSS, and vanilla JavaScript — no external JavaScript libraries.
